# **App Name**: ecbills.in

## Core Features:

- Rapid Billing: Enable quick billing with buy, sell, and return modes, navigable via keyboard inputs.
- Intelligent Product Suggestions: Offer a dropdown suggestion list during product name input for faster selection and auto-filling of details.
- Dynamic Product Entry: Display a popup for adding new product details (name, category, tracking options) when a product isn't found, prioritizing speed.
- Defective/Good Tracking: Create an interface for users to log products as either good or defective when being returned, which updates stock levels accordingly.
- Real-time Dashboard: Present an overview dashboard showing total products, today's sales and purchases, customer count, and defectives.
- AI-Assisted Categorization: Provide an intelligent tool to identify opportunities to automatically categorize new products using descriptions of previous ones, reducing manual data entry.

## Style Guidelines:

- Primary color: A cool, muted blue (#6699CC) evoking reliability.
- Background color: A very light, desaturated blue (#F0F8FF) for a clean, professional look.
- Accent color: A vibrant purple (#A673D9) to draw the eye to actionable elements.
- Clear, sans-serif fonts for enhanced readability across all devices.
- Use a consistent set of minimalist icons to visually represent categories and actions.
- Design a responsive layout that adapts seamlessly to mobile, tablet, and desktop screens.
- Incorporate subtle transitions and feedback animations to enhance user interaction.
